# 賽博宮

把台灣民俗儀式套進寫程式日常的 Windows 桌面 App（Electron + TypeScript）。

目前進度：**M5，規格裡的五個階段都已實作**（擲筊引擎、功過簿、主殿、系統匣、擲筊 push、農民曆宜忌、籤詩 code review、變數姓名學、陰間回收筒、收驚、中元普渡、綠色乖乖）。

## 在 Windows 上試用

需要先裝 [Node.js](https://nodejs.org/) 22 以上。

```
cd saibo-gong
npm install
npm start
```

- 關掉視窗只是收進系統匣（右下角）；要真正結束，在系統匣圖示按右鍵選「離開」。
- 資料存在 `%APPDATA%\DigitalTemple\`：`ledger.jsonl`（功過簿）、`ledger.head.json`（封印）、`stats.json`（擲筊統計）、`settings.json`。
- 想試又不想弄髒正式的功過簿，可以先設環境變數 `SAIBO_DATA_DIR` 指到別的資料夾再啟動。

## 擲筊 push

在主殿的「擲筊 push」卡片安裝：

- **為某個 repo 安裝**：只在那個 repo 的 `.git/hooks` 放一個 `pre-push`。repo 已經有別的 pre-push hook 時不會蓋掉它。
- **全域安裝**：把 git 的全域設定 `core.hooksPath` 指到 `%APPDATA%\DigitalTemple\hooks`，所有 repo 都生效；各 repo 原有的 hook 會被轉交執行。

之後 `git push` 會先叫出主殿：

1. 當天忌開市、而且是正式上線（push 到受保護的分支，預設 `main`、`master`；或任何 tag）→ 直接擋，可打懺悔文硬闖。
2. 接著擲筊，三次為限。聖筊放行；擲不到可以硬闖（懺悔文，記入功過簿）或作罷（push 取消）。

主殿沒開時 hook 會自己把它叫起來；等不到回應就放行，並在功過簿記一筆「神明不在」。閉廟時一律直接放行。

想模擬忌開市的日子，啟動前設環境變數 `SAIBO_FAKE_DATE`，例如 `2026-11-14`。

## 籤詩 code review

在主殿的「籤詩 code review」卡片選一個 repo 按「抽籤」。它會：

1. 找出這次的改動（和上次 push 比較，含還沒 commit 的修改）。
2. 依語言呼叫免費的靜態檢查工具，只看改動到的行：

   | 語言 | 工具 | 安裝 |
   |---|---|---|
   | C/C++ | cppcheck | `winget install Cppcheck.Cppcheck` |
   | Python | ruff | `pip install ruff` |
   | JS/TS | eslint | 專案內 `npm install -D eslint`，或 `npm install -g eslint` |

   沒裝的工具會提示並跳過那個語言。專案沒有 eslint 設定檔時，改用內建的基本規則（只檢查 JS）。
3. 依問題的嚴重度加權、除以改動行數算出分數，對應上上、上吉、中吉、中平、下下，抽一支籤。

籤上有三段：**籤詩**（四句七言）、**解曰**（把問題翻成民俗說法）、**白話**（每個問題的檔案、行號、檢查工具的原文）。

勾選「push 前自動抽籤」後，每次 push 會順便抽一支，只顯示、不擋。

**變數姓名學**：抽籤時一併算這次新增的名字（變數、函式、類別）的筆畫，套八十一數理，屬凶的列在「宜改名」。中文字查真實筆畫，英文字母照手寫大寫的筆畫；對照表在 `%APPDATA%\DigitalTemple\letter-strokes.json`，可以自己改。

籤詩全部是本專案自行創作，共 50 支。

## 電腦管理

這三項會動到你的檔案或執行中的程式，**真的動手前一律先跳確認視窗**。

### 陰間回收筒

- **燒給它**：在主殿按「燒給它…」選檔案，或勾選「檔案總管右鍵選單」後在檔案上按右鍵（Windows 11 要先點「顯示其他選項」）。檔案會搬到 `%APPDATA%\DigitalTemple\underworld`，不會刪除。Windows 原本的刪除和資源回收筒完全不受影響。
- **請回陽間**：擲到聖筊才還原到原本的位置，不限次數。
- **強制還陽**：不擲筊直接還原，隨時可用（閉廟中也可以），會記入功過簿。原位置有同名檔案時會改名不覆蓋；原資料夾回不去時放到桌面的「賽博宮還陽」。
- **超渡**：在陰間超過 30 天的檔案會提議移到 Windows 的資源回收筒，確認後才執行。

### 收驚

每五分鐘讀一次 Windows 事件記錄裡的應用程式當機事件。同一個程式一小時內當掉三次就判定「被嚇到了」，可以幫它收驚；儀式結束後詢問要不要重新啟動，確認才啟動。

### 中元普渡

農曆七月會提醒，七月十五主動通知；其他時間可以手動辦「小普渡」。名單有兩類：

- **沒有回應的程式**：預設勾選。
- **殘留在背景的程式**（沒有視窗、執行超過 2 小時、幾乎沒用 CPU）：預設不勾。

系統程式（`C:\Windows` 底下）、系統服務、防毒軟體、賽博宮自己，以及你填在「永遠不碰的程式」裡的，永遠不會出現在名單上。勾選後還要再確認一次才會結束程式。

## 綠色乖乖

在主殿右側的「綠色乖乖」卡片按「供奉新乖乖」，用鏡頭拍包裝或上傳照片：

- 先檢查包裝的主色是不是綠色，**其他口味不算**，不是綠色就不能供奉。
- 再用本機的文字辨識讀有效日期，讀到後請你確認；讀不到就手動輸入。照片只在這台電腦上處理，不會傳出去。

乖乖過期後會「不乖」，三種效果全部只是視覺效果：

| 效果 | 說明 |
|---|---|
| 桌布歪掉 | 把目前的桌布轉 3 度。原本的桌布檔案不會被改動，還另外備份一份。純色背景或幻燈片桌布不處理。 |
| 游標偶爾抖一下 | 每 2 到 6 分鐘最多一次，抖幾個像素就回到原位；你按著滑鼠鍵時不抖。 |
| 畫面掉碎屑 | 每 1 到 3 分鐘一陣。畫在透明、滑鼠可穿透的視窗上，不擋任何操作。 |

以下任何一種方式都會**立刻還原全部效果**，桌布回到原本那一張：

- 供奉一包沒過期的新乖乖
- 按「暫時安撫」（停用一小時，不記功過簿）
- 閉廟
- 在「各殿功能」關掉綠色乖乖
- 離開賽博宮

App 被強制結束時桌布會暫時維持歪的，下次開啟後用上面任一方式即可還原。

## 開發

| 指令 | 作用 |
|---|---|
| `npm test` | 核心邏輯測試（擲筊、功過簿、懺悔文、農民曆、push 判斷、籤詩、姓名學、陰間、收驚、普渡、乖乖） |
| `npm run typecheck` | 型別檢查 |
| `npm run build` | 打包到 `dist/` |

程式碼分成 `src/core`（不碰畫面的邏輯）、`src/main`（Electron 主程序、系統匣、git hook 用的小程式）、`src/renderer`（主殿畫面）。

農民曆使用 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT），中文筆畫使用 [cnchar](https://github.com/theajack/cnchar)（MIT），文字辨識使用 [tesseract.js](https://github.com/naptha/tesseract.js)（Apache-2.0）。三者都在本機執行，不需要網路。
